Para rotacionar anti-horário: [x = y, y = -x]

PS: Se um valor de x ou de y for menor que 0, procuramos o menor entre todos deste grupo, e
adicionamos "esse valor * -1 (para ser positivo)", a todos os outros valores do seu grupo de x ou de y, e
isso se aplica para ambos.

ex: aqui apenas os valores de y chegaram abaixo de 0, então aplicamos a regra: O menor valor é o -2 e, -2 * -1 igual
à 2, adicionamos os 2 a todos os valores de y, independentemente se entre eles há valores >= 0, desde que um deles
seja menor que 0 essa regra se aplica
